# Adventure Land: The Offline Fantasy RPG with Code: single-player files

This folder holds the single-player parts of Adventure Land: The Offline Fantasy RPG with Code:

- `config\`: the local config, linked as `secretsandconfig` by `Play.bat`.
- `data\`: your saved game (the database). It's made on the first start.
- `web.js`: switches off the online-only website parts and logs you in automatically.
- `text.js`: changes the game's text as it loads, in every language.
- `init_db.js`, `stop_db.js` and `wait_port.js`: helpers used by `Play.bat` and `Stop.bat`.

How to install, play, stop and change settings, plus the full list of changes by version, is in the main `README.md`.
